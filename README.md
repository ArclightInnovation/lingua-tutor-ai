# 🌐 LingoTutor AI — Mobile-First Conversational Language Learning Platform

An AI-powered language-learning web platform combining **Google Gemini 2.5 Intelligence** (curriculum planning, placement assessments, spaced repetition, post-call analysis) and **ElevenLabs Conversational AI Agents** (real-time voice tutoring, pronunciation practice, scenario roleplay).

---

## 📱 Features

- **🏠 Home Dashboard:** Daily 20-minute adaptive study plan, study streaks, CEFR progression, and "Continue Learning" one-tap action.
- **📚 Structured Curriculum:** Complete CEFR course hierarchy (Course → Level → Unit → Lesson → Activity) supporting Spanish, French, German, Italian, Mandarin, Japanese, Korean, Portuguese, Arabic, and English.
- **🎙️ Talk to Your AI Tutor:** Real-time spoken conversations powered by ElevenLabs Web WebSocket AI Agents & Google Gemini. Supports 10+ real-world roleplay scenarios (Restaurant, Hotel, Airport, Job Interview, Shopping, Medical).
- **🔄 Spaced Repetition Vocabulary Bank:** SM-2/FSRS-inspired Flashcard review algorithm, personal phrasebook, and mistake notebook.
- **👤 Learner Personalization:** Onboarding questionnaire, adaptive placement assessment, customizable tutor personality, immersion level settings, and immediate/delayed correction preferences.
- **🔒 Password Security & Client-Side Encryption:** Locked with SHA-256 cryptographic passcode gate (`Andizzle19902026!`), with encrypted local API key storage.
